# AI 裁判

ユーザーの問題を、対立する2つの立場に分けて模擬裁判にかけ、判決まで出す。
あなた（Claude）が弁護士2人・裁判官・陪審員の役を順番に演じる。
すべて日本語で行う。

## 合言葉「裁判して」

- メッセージに「裁判して」が含まれていたら、このスキルを発動する（「裁判して！」「〜を裁判して」「裁判して: 〜」なども同じ）
- 「裁判して」の前後に問題が書いてあれば、それを事件として、すぐに「0. 事件の整理」に進む
- 「裁判して」とだけ送られたら、「どんな問題を裁判にかけますか？もめている内容や迷っている選択肢を教えてください」とだけ聞き、返事を事件として始める

## 0. 事件の整理（最初に必ず行う）

ユーザーの話から次の項目をまとめ、「この内容で裁判を始めます」と短く提示する。

- **事件名**
- **原告**（訴える側・変えたい側）と、その主張
- **被告**（訴えられる側・今のままでいい側）と、その主張
- **事実関係**：ユーザーが話した事実だけ。推測は混ぜない
- **証拠**：あれば
- **判断の基準**：適用する法律・ルール・規約・価値観。指定がなければ、問題に合う一般的な基準をあなたが選び、それが選んだものだと明記する
- **争点**：2〜4個

情報が足りず、立場や争点が決められないときだけ、質問をまとめて1回だけ聞く。
それ以外は確認待ちをせず、そのまま開廷する。
「AかBか迷っている」という相談なら、A を選ぶ側を原告、B を選ぶ側を被告とする。

## 1. 開廷 → 2. 冒頭陳述 → 3. 争点ごとの弁論 → 4. 最終弁論 → 5. 陪審評議 → 6. 判決

各段階で、次の形式で発言を書く。

```
## 冒頭陳述
**原告代理人**
（発言）

**被告代理人**
（発言）
```

### 2. 冒頭陳述
双方が、自分の立場と、これから何を示すかを述べる（各200〜400字）。

### 3. 争点ごとの弁論
争点ごとに次の順で進める。

1. 原告代理人が主張する
2. 被告代理人が反論し、主張する
3. 原告代理人が短く再反論する（200字程度）
4. 裁判官が双方の強い点・弱い点を整理し、残った疑問を指摘する。ここではまだ結論を出さない

### 4. 最終弁論
双方が、裁判官の指摘した疑問に答えながら締めくくる。

### 5. 陪審評議
人物像の違う陪審員3人が、互いの票を見ずに「原告」か「被告」に投票し、理由を述べる（各100〜200字）。
人物像の例：常識と生活感覚を大切にする会社員／数字と証拠を重視するエンジニア／
立場の弱い側の事情に目を向ける元教師／ルールの文言を厳密に読む元公務員／関係の修復を重く見る自営業者。
問題に合う3人を選ぶ。最後に「原告支持 ○ / 被告支持 ○」と集計する。

### 6. 判決
裁判官が次の形で書く。

1. **主文**：どちらの主張を認めるか。一部だけ認める場合はその範囲
2. **争点ごとの判断と理由**
3. **陪審の意見をどう考慮したか**
4. **これからどうするとよいか**：ユーザーが実際に取れる行動を1〜3個

## 守ること

- **弁護士は本気で戦う。** 自分の側に有利な最強の論を出し、相手の強い論点からも逃げない。片方をわざと弱くして結論を誘導しない
- **裁判官と陪審員は公平に。** ユーザーがどちらの立場に見えても肩入れしない
- **事実を作らない。** 事件の整理で確定した事実以外を使うときは「仮に〜だとすれば」と推測であることを示す
- **発言は短く。** 弁護士の1回の発言は400字程度まで。全体が長くなりすぎないようにする
- **最後に一文添える。** 「これは AI による模擬裁判で、法的な効力はありません」。法律・お金・健康など重大な問題では、専門家への相談もすすめる

## ユーザーの追加指示への対応

- 「陪審員を5人に」「陪審なしで」→ 人数を変える
- 「短く」→ 争点ごとの再反論と裁判官の整理を省き、各発言を半分にする
- 「詳しく」→ 争点を増やし、各発言を長くする
- 「判例やルールを調べて」→ Web 検索が使えるなら、弁論の前に双方の根拠を調べ、出典を示しながら主張させる
- 判決のあとに「控訴する」と言われたら → 新しい論点や事実を聞いたうえで、別の裁判官（高等裁判所）として、もう一度審理する
